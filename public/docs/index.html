SIMAGANG DTEDI API Documentation

Dokumentasi resmi untuk modul Super Admin dan Admin Program Studi (TRPL, TRIK, TRI, TRE). Berfokus pada otorisasi multi-prodi, manajemen akun pengelola, master data, monitoring magang, dan presentasi proyek industri.

🚀 Base URL: http://127.0.0.1:8000/api 🔒 Auth: Laravel Sanctum Bearer Token 🛡️ Multi-Prodi: TRPL (1), TRIK (2), TRI (3), TRE (4) ⬇️ Unduh Koleksi Postman JSON

02. Admin Prodi: Dashboard Terisolasi
GET /api/dashboard/admin
Dashboard Metrik Khusus Prodi Admin
Role: admin
Metrik jumlah_mahasiswa dan jumlah_mahasiswa_aktif_magang hanya menghitung data dari prodi admin yang sedang login.
03. Admin Prodi: Manajemen Mahasiswa
GET /api/mahasiswa
List Mahasiswa (Isolasi Prodi)
Role: admin
Admin TRPL hanya akan melihat daftar mahasiswa dengan prodi_id: 1. Mahasiswa dari TRIK, TRI, TRE tidak muncul.
POST /api/mahasiswa
Tambah Mahasiswa Baru
Role: admin Body:
{ "nim": "24/500001/SV/10001", "nama": "Mahasiswa Uji TRPL", "angkatan": "2024" }
Nilai prodi_id otomatis diambil dari profil admin yang sedang login. Jika klien menyertakan prodi_id lain di payload, sistem otomatis mengabaikannya.
GET /api/mahasiswa/{id} (Uji Lintas Prodi)
Proteksi IDOR Mahasiswa
403 Forbidden
{ "message": "Unauthorized. Mahasiswa bukan dari prodi anda." }
04. Admin Prodi: Manajemen Jadwal Presentasi PI
POST /api/jadwal-presentasi
Buat Jadwal Presentasi Mahasiswa
Role: admin / super_admin Body:
{ "magang_id": 1, "tanggal_presentasi": "2026-11-20", "waktu_mulai": "09:00", "waktu_selesai": "10:30", "ruangan": "Lab Software 201", "tempat": "Gedung TILC SV UGM", "keterangan": "Presentasi Akhir Proyek Industri", "status": "terjadwal" }

Admin prodi hanya dapat menjadwalkan mahasiswa dari prodinya sendiri. Jika magang_id merujuk pada mahasiswa prodi lain, server menolak dengan HTTP 403 Forbidden.
